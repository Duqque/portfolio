# Audio

Le prototype est 100 % synthétique (WebAudio + synthèse vocale du navigateur).
Pour passer aux vrais fichiers, ajoutez ici :

- `narration/<building-id>.mp3` — voix masculine, française, calme, légèrement grave (renseignez `audio` dans `src/data/buildings.ts`)
- `music/{origins,build,competition,world,lisbon,future,final}.mp3`
- `ambience/{ville,voitures,train,gare,dojo,tatamis,ecole,foule,avions,port,stade,circuit,chantier,vent,oiseaux,nuit}.mp3`
